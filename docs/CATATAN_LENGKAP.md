# Catatan lengkap Lab Investasi Syariah (arsip catatan ringkas sampai 2026-10-23)

Ringkasan aktif ada di catatan ringkas proyek (lokal). File ini berisi detail teknis dan riwayat lengkap; cari bagian yang perlu dengan grep. Jangan baca ulang file besar atau CSV utuh (pakai `head`, `describe`, `wc -l`). Jangan paste respons JSON besar ke chat.

## Tujuan dan batasan
- Cari saham syariah IDX dengan return **net >= 3%**, ideal dalam <= 1 minggu (horizon lain boleh).
- **Hanya saham syariah** (`data/syariah_tickers.txt` 217 ticker; untuk uji baru pakai DES historis `data/des/des_historis.csv`).
- Masih **uji coba, belum ada uang keluar**. Tujuan: cari metode/simulasi terbaik, jujur soal hasil.
- Bukan nasihat keuangan. Jangan klaim edge dari data in-sample saja.

## Stack aplikasi (2026-10-21)
MongoDB lokal (service Windows `MongoDB`, otomatis jalan) + FastAPI (Python) + Vue 3 + Tailwind. Backend sengaja Python supaya logika backtest/paper trade tidak ditulis ulang.

**Penyimpanan data (2026-10-23, permintaan user: semua di DB, tidak ada folder `data/` lagi)**: dua database. `swing` = state aplikasi (paper, backtest, fundamental, des, reksa dana, dll; backup harian). `lab_data` (env `SWING_DATA_DB`) = data pasar & sumber, lewat `backend/db/data.py`: `dt.baca('harga/AALI')`/`dt.tulis(nama, df)` (1 dokumen per tabel/saham, kolom = array, tabel > 10.000 baris dipecah `nama#0000`; round-trip identik dengan parquet, termasuk dtype), `dt.daftar(koleksi)`, `dt.baca_banyak(koleksi, kunci, kolom)`, `dt.versi(nama)` (untuk cache), `dt.simpan_hasil/baca_hasil` (koleksi `hasil_riset`: DataFrame, JSON, atau teks; `dt.hasil_teks('status_h16')` mirip Path), `dt.simpan_daftar/baca_daftar` (`syariah_tickers`, `nonsyariah_kode`, `des_kode`), arsip file sumber di GridFS bucket `arsip` (`dt.simpan_arsip(nama, bytes, folder)`, folder: fundamental, ojk_nab, ksei, des, mentah, invezgo). `https://www.idx.co.id/primary/TradingSummary/GetStockSummary?length=9999&start=0`
